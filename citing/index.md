# How to cite

There is no paper to cite yet. When there is, it will be linked here.

## Until then

Cite the code you used, with the commit. Record it with `git rev-parse HEAD` in each repository and add it to your reference, for example `note = {commit 1590e6d}`.

## Cite the version, not the name

The database is still being extended, so a result has to name the release it was computed against. Each release is recorded in the database (`meta.release`), and this site will list the release behind each published result.

## Cite the sources

The data comes from public archives maintained by others: the kernel mailing-list archives at lore.kernel.org, the mainline repository `torvalds/linux`, kernel Bugzilla, and historical Usenet archives. Acknowledge them.
